# Security Policy / Politique de sécurité

[English](#english) · [Français](#français)

## English

NiakPS5 is experimental homebrew software for PS5. Its local launch broker binds to `127.0.0.1` only. Never publish Sony system files, saved games, credentials, account data, or private console configurations in this repository.

To report a vulnerability, prefer **GitHub → Security → Report a vulnerability** if enabled. Otherwise, open an issue requesting a private disclosure channel **without** including passwords, personal information, reusable exploit details or confidential console logs.

Remove private IP addresses, account identifiers, usernames, local paths and tokens before sharing logs. Check screenshots for identifiable account or profile information.

There is no guarantee that code validated on a PC or through CI is safe on all PS5 firmware versions. Test only with backups and respect device and platform security boundaries.

## Français

NiakPS5 est une application homebrew expérimentale pour PS5. Le service de lancement n'écoute que sur `127.0.0.1`. Aucun fichier système Sony, sauvegarde, clé API ou configuration personnelle ne doit être publié dans ce dépôt.

Pour signaler une vulnérabilité, privilégier **GitHub → Security → Report a vulnerability** lorsque cette fonction est disponible. À défaut, ouvrir une issue ne contenant **aucune donnée personnelle, aucun secret et aucune preuve d'exploitation réutilisable**, pour demander un canal de communication privé.

Avant de fournir des journaux, retirer les adresses IP privées, noms d'utilisateurs, identifiants de compte, chemins personnels, cookies et jetons. Les captures d'écran peuvent contenir des données de profil et ne doivent pas être publiées sans vérification.

Les mises à jour ne prétendent pas contourner les protections de licences, du disque, du firmware ou du système d'exploitation. Ne jamais tester une modification destructive directement sur sa seule console.
